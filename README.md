# Luna & Stone Jewelry

A beginner-friendly jewelry storefront demo.

## How to view it

Open `index.html` in a web browser. No installation is required for this first version.

## What is included

- Responsive homepage
- Jewelry product cards
- Shopping bag that can add and remove products
- Brand story section
- Mobile-friendly layout

Checkout is intentionally a demo for now. A real store will later need product photos, inventory, shipping, payments, and order management.
